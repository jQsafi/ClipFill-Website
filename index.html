Built for Speed & Privacy

Designed to boost your workflow without tracking your data.

🎯

Smart Click-to-Fill

Click any snippet in the sidebar to populate the currently focused input box on any active webpage instantaneously.

📋

Auto Clipboard History

Monitored copy actions dynamically save snippets to your sidebar history, with 1-click toggle controls.

🔍

Smart Form Inspector

Scans forms on the active page and maps your personal profile info (Name, Email, Phone) automatically.

📌

Pin & Categorize

Organize items by categories (*Personal*, *Form Data*, *General*, *Code*) and pin high-priority items to top.

🔒

100% Local Storage

All snippets and history are saved strictly in your browser storage (`chrome.storage.local`). Zero cloud tracking.

🌐

Cross-Browser Support

Fully optimized and tested on both Google Chrome and Microsoft Edge browser sidebars.

Quick Installation Guide

Load ClipFill in developer mode in under 60 seconds.

🌐
Google Chrome
  • 1
    Clone repository branch:
    git clone https://github.com/jQsafi/ClipFill.git
  • 2
    Open Chrome and navigate to chrome://extensions
  • 3
    Enable Developer mode in the top-right corner toggle.
  • 4
    Click Load unpacked and select the project directory.
🌀
Microsoft Edge
  • 1
    Clone Edge branch:
    git clone -b ClipFill-Edge https://github.com/jQsafi/ClipFill.git
  • 2
    Open Edge and navigate to edge://extensions
  • 3
    Enable Developer mode in the bottom-left sidebar toggle.
  • 4
    Click Load unpacked and select the project directory.
